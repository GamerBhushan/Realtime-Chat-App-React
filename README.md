# Realtime-Chat-App-React ![Build Status](https://img.shields.io/badge/status-active-brightgreen)

## ✨ Developed by Bhushan  
A fast and seamless Chat App built with **React, Vite & TypeScript**, featuring real-time messaging using WebSockets.

---

## 🚀 Features

- ⚡ **Real-time messaging** using WebSockets.
- 🔄 Fast performance with **Vite**.
- 🔧 Built with **TypeScript** for better type safety.
- 🎨 Fully responsive UI.

---

## ⚡ Tech Stack

- **Frontend:** React + Vite + TypeScript
- **WebSockets:** Socket.io

---

## 🛠️ Installation & Setup

Follow these steps to run the project locally:


### 1 **Install Bun and Clone the Repository**
```sh
npm install -g bun
git clone https://github.com/GamerBhushan/Realtime-Chat-App-React.git
cd Realtime-Chat-App-React
```


### 2 **Install Dependencies**
```sh
cd server
bun install
cd ..
cd client
bun install
cd ..
```


### 4 **Run the Project**
```sh
cd server
bun run src/index.ts
cd ..
cd client
bun run dev
```
- The Server Will Start On **`http://localhost:3000`** 
- The app will start on **`http://localhost:5173/`** (default Vite port).
